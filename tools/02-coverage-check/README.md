# The five-line coverage check

**Time:** 15 minutes a day once set up · **Needs:** record counts from each data feed · **No AI needed**

Several of the largest recent fines were not about bad judgement. Data never reached the system, or part of a list was left out, and "no alerts" looked like good news.

## The five lines
Run these every day, for every feed into screening and monitoring:

1. **Records in:** how many records left the source system?
2. **Records screened:** how many did screening or monitoring actually process?
3. **The gap:** line 1 minus line 2. Anything other than zero needs a named reason.
4. **List completeness:** after every sanctions or watchlist update, does the entry count match the publisher's count?
5. **Silence check:** did any rule or feed produce zero alerts for longer than usual? Treat silence as an incident until explained.

## What this can't do
It shows that data arrived, not that the rules are good. Pair it with the three tests for a real review.
